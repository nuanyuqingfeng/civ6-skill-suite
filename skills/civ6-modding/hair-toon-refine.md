# hair-toon-refine — 领袖头发 BaseColor 的 Toon 观感精修（备选流程，非默认路径）

> **这是一个按需路由的备选流程，不是所有美术任务的默认步骤。**
> 只有当用户明确表达「头发看着不对」时才进入；纯图标/立绘/几何/材质类问题走 `art-pipeline.md` 或 `civ6-art-reference`。

---

## 0. 何时进入本流程

### 0.1 命中即进入（关键词）

| 类别 | 用户可能说的话 |
|---|---|
| **糊 / 没层次** | 头发很糊、头发糊了、发丝糊、头发层次感、没层次、头发一片平、发束看不清、暗部糊成一团、头发死黑、头发像一块布、头发没有细节 |
| **优化 / 精修** | 头发优化、头发修一下、头发精修、头发重做、头发再调调、头发观感不对、头发质感不行、接近官方头发、头发不像游戏里的 |
| **塑料 / 发白** | 头发塑料感、头发像塑料、头发发白、银灰亮块、头发泛白、高光太硬、高光一条白线、头发发亮过头、头发油光 |
| **偏色 / 明暗** | 头发偏蓝、头发偏灰、头发发闷、头发太亮、头发太暗、头发染色不对、头发颜色不脏不净 |
| **槽位直指** | 头发贴图、Hair BaseColor、刘海发灰、鬓发没层次、头发材质、hair、toon hair |

### 0.2 不进入（去别处）

| 症状 | 真正的去处 |
|---|---|
| 头发**穿模 / 悬空 / 顶点抖动 / 发束几何断裂** | 几何与蒙皮问题，非本流程（走模型导入链 / `civ6-art-reference`） |
| 头发**边缘锯齿 / 剪影镂空** | 多为 Opacity / alpha-test，走 `art-pipeline.md` + 材质 Opacity 槽 |
| 头发**没有高光反应、视角一转就变** | 材质类缺 specular，`Leader_Matte` 天花板问题，本流程只能静态近似 |
| 只是**换发色**（指定一个 RGB） | 直接改 BaseColor 色相即可，不必跑六步 |
| 图标 / 立绘 / 背景 | `art-pipeline.md` / `civ6-asset-forge` |

### 0.3 一句话原理

`Leader_Matte` 直出会把源 `_D` 自带的赛璐璐硬边白斑**原样带进游戏**，而官方的 `MSM_ToonHair` 靠 `UseUVGradient` + `MaskTex` 重建宽而柔的带状高光、且 `SolidShadowStrength=0` 不压死暗部。所以观感差**不是"不够亮"**，而是**分布形状被拉成两头**：亮部更白更硬、暗部更黑更平。本流程不改材质，只在 BaseColor 上把这层缺失的代数残影补回去。

## 2. 步骤

### 步骤 0 · 备份硬闸门（先于任何写操作）

备份到 `<SLN>/workspace/gen/backup/tex_before_hair_<时间戳>/`：

- 头发 `BaseColor` `{Hair,Bangs}×{dds,tex}`
- 头发 `Opacity` `{Hair,Bangs}×{dds,tex}`（**即使是纯白 no-op 也要备**）
- 材质 `{Hair,Bangs,Bangs_Dark}.mtl`
- 该领袖**已部署**的 BLP

生成 `MANIFEST.sha256`，并校验：BaseColor DDS 大小 = `128 + 4·Σ(2048>>k)²`（k=0..11）= **22,369,748 B**、`.tex` 为 2048/2048/12。不符即停。同时写好一键回退脚本（恢复贴图 + BLP，无需重 cook）。

### 步骤 1 · 体检（只读）

1. `_HM.png` 是否为 RGBA：**R≈0、B 恒 255 是正常的，只有 G 有信息**；打印 G 的 p95/max 作残差归一依据。若 G 近乎全黑 → 源格式不对，停。
2. 现网 `BaseColor.dds` 是否 2048²/12mip/未压缩 RGBA；`.tex` 是否 2048/2048/12。
3. 现网 `.mtl` 是否 `Leader_Matte`（通常只有 BaseColor，Opacity 常空绑）。
4. **定量基线**：同一头发掩膜下，对官方图、实机图、现网贴图分别测 `p5/p50/p95/p99`、`>110` 占比、`<25` 占比、饱和度、`B−R`、`|L−blur3|`、均值。由此定：① 亮度锚点 ② 该领袖自己的色轴（暗端→亮端）③ 目标方向。

> 不要照抄别的领袖的色轴。粉发/金发/蓝发的暗端与亮端差别很大。

### 步骤 2 · 出预览（不落盘）

```bash
python <skill>/art/hair_toon_refine.py --config job.json preview
```

产出：`refined_compare.png`（改前/改后并排）+ 逐张指标表。

**方向判据**（相对改前）：`>110` 明显下降、`p99` 下降、`<25` 趋 0、`sat` 与 `B−R` 上升、`hp`（高通）下降、**均值变化 ≤ ±3**；视觉上宽而柔的带状高光、暗部仍有发束分层、无硬边银白块。

不达标只调参数重出预览，**不得直接 apply**。

### 步骤 3 · 应用

```bash
python <skill>/art/hair_toon_refine.py --config job.json apply
```

内置校验（任一不过即退出码 2，不会写盘）：DDS 头与基准逐字段一致 → 文件大小 = `128+4Σmip²` → **mip0 与预期图逐像素 MAE=0** → alpha 全 255 → `.tex` 仍 2048/2048/12。

### 步骤 4 · cook / 部署

只 cook 该领袖包。闸门：`COOK_EXIT=0`、告警 0、`FALLBACK=0`、成功行 ≥1、部署 `cmp=0`。

**BLP 不热重载 —— 必须完整重启游戏才生效**，只重开外交界面无效。

## 3. 六步算法与参数

| 步 | 做什么 | 关键参数（默认） |
|---|---|---|
| **D1** | 拆源 `_D` 的赛璐璐硬边白斑：亮区亮度往局部均值收缩，边界随之柔化 | `blob_t0/t1`=100/180、`blob_soft`=0.60、`blob_blur`=20 |
| **D2** | 读 `_HM` 的 **G 通道**重建宽/窄双层柔高光 | `spec_wide_r/narrow_r`=12/3、`spec_mix`=0.65、`spec_lum`=0.12、`spec_tint`=0.22 |
| **D3** | 沿 UV-V 的顶部渐变，官方有 `GradientColor` 用官方值 | `grad_w`=0.07、`grad_p`=1.4、`grad_color`=#E3F5FB |
| **D4** | 暗部抬升，不压成死黑 | `shadow_lift`=0.08、`shadow_knee`=45 |
| **D5** | ★ 亮度分位锚定到改前现网基底 + 暗调回注高频 | `anchor_lift_p5/p50`=+6/+1、`anchor_drop_p95`=−12、`anchor_tail`=0.42、`detail_gain`=0.20（仅 `<110`） |
| **D6** | 双色调，色偏只落亮部 | `duotone`=0.45、`tint_gamma`=1.8、`shadow`/`tint`=**实测** |

**D5 是全流程支点**：不锁亮度，实机会出现「贴图漂亮、游戏里整片发亮/发闷」的跳变。禁止改成全局乘系数或整体提亮/压暗。

**色轴示例**（本项目秧秧，冷蓝黑，仅作形状参考，不要照抄数值）：
暗端 `[34,38,56]` → 亮端 `[95,142,200]`，渐变 `#E3F5FB`。

## 5. 调参入口

| 实机若… | 改哪个 |
|---|---|
| 整体偏暗 / 发闷 | `anchor_lift_p50` +3~5、`anchor_drop_p95` 减小 |
| 刘海过平无高光 | 提高该槽 `p95_cap`、`anchor_tail` 0.42→0.50 |
| 仍见硬边浅色块 | `blob_blur` 20→32、`blob_soft` 0.60→0.70 |
| 偏色 / 过饱和 | `duotone` 0.45→0.35，或重测色轴 |
| 发丝太锐 | `detail_gain` 0.20→0.12 |
| 高光太宽/发虚 | `spec_wide_r` 12→8、`spec_mix` 0.65→0.72 |

## 6. 陷阱（都踩过）

1. **`convert("L")` 读 `_HM`**：它其实是 RGBA，`convert("L")≈0.587·G+29`，把 41% 动态范围压掉还垫了常量底色。必须取 G。
2. **`Bangs_Dark` 无独立贴图**，与 `Bangs` 共用 → 改 2 张覆盖 3 个槽。
3. **纯白 `*_Opacity.dds` 当遮罩绑回是 no-op**（9 份 mtl 已解绑）。真要做发尖剪影，得用 `_D` 的 alpha 且单独验证。
4. **历史中间版本不要叠加**：整体压暗 0.55、×1.6 提亮、软遮罩、法线实验、双色分离、锐化、HM MID、depth+duotone —— 全部证伪，只留 D1~D6。
5. **源与工程前缀大小写不一致**会静默读错文件。
6. **BLP 不热重载**，改完必须完整重启，否则会误判"没效果"而叠加第二轮改动。
7. **`Leader_Matte` 的天花板**：没有视角相关高光、NdotL ramp、描边，静态烘焙只能在固定机位近似。想 100% 复现官方要换材质类，成本远高于收益，先说明再决定。
