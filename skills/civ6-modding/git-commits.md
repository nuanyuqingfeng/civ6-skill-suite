# Git 提交规范（主题 = 目的）

> 目的：提交主题是更新说明（`workshop-intro.md` §5.3）与台账的上游素材。
> 主题写**目的**、细节进 **body**，更新条目时 AI 的提炼量趋近于零。

## 主题行（硬性）

- 一句话、**目的/效果导向**：`修复声痕贴图边缘瑕疵`、`男漂待机改为自然站立`。
- **禁**实现细节与数字：面数、字节数、哈希、坐标偏移、骨骼名等一律进 body。
- 允许 `fix:` / `feat:` 类前缀，但前缀后仍须是目的句；无前缀亦可。
- 长度宜 ≤ 30 字。

## body（细节与归因）

- 具体改动：如 `Geometries/RoverUnit.geo` `m_nPrims 22→3314`、骨权重继承策略、文件清单。
- 关联：goal 文档名、相关 commit、台账版本行。
- body 是台账「历史版本」行 ① 小节的取材处；**changeNote 不读 body 细节**。

## 正反例

| 反例（细节入主题） | 正例（目的入主题） |
|---|---|
| `声痕面片按星形轮廓重建为 3314 面` | `修复声痕面片显示瑕疵`（body：星形轮廓重建 3314 面…） |
| `声痕贴图透明区清零` | `修复声痕贴图透明区瑕疵`（body：透明区 RGBA 清零） |
| `声痕面片贴合加米制偏移，骨权重随顶点继承` | 并入上一条 body，不单独成提交 |

> 历史提交不追溯改写；本规范自 2026-11-05 起生效。历史素材偏细节时，由 AI 按
> `workshop-intro.md` §5.3 兜底提炼，不照抄。
