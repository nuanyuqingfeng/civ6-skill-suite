# 二次运动：发丝与衣物

解包素材里没有发丝动画（UE 侧由运行时物理驱动）时，二次运动要在烘焙阶段程序化补出来。本文记录今汐工程（2026-10）实机验证过的做法与判据。

## 一、两套解算器

| 解算器 | 适用 | 做法 |
|--------|------|------|
| 角度弹簧 | 短链（3 到 4 节）、裙摆、飘带 | 每帧把骨的世界朝向按弹簧阻尼拉向基础姿态，输出相对父骨的旋转增量；参数按族标定 |
| 质点链 | 8 节以上长链 | Verlet 积分（位置 + 上一帧位置）、距离约束 12 次、弯曲形状约束每帧一次、绕脊柱轴回转体碰撞 |

## 二、管线约定（违反即全链散架）

- 世界矩阵按绝对局部累积：`world = parent_world @ LocRotScale(loc*ANIM_SCALE, quat, scale)`。`rest_rel` 只用来取节长，不能再乘一次。
- 输出给通道的 basis 是父骨相对：`parent_rot^-1 @ rot`，不混入 rest_rot。
- 末端质点的目标方向取链条延伸方向（末两骨关节连线）。取末骨自身 Y 轴会实测偏 90 度，末端质点被拉到侧方，画面只有末节在动。

## 三、根骨与碰撞

- 第 0 节不参与仿真，直接跟随动画姿态（Kawaii Physics 与 DanceXR 都这么做）。
- 碰撞只在肩线以下生效（今汐取 z 小于 105 厘米）。发根落在身体回转体半径内时，推出与回拉逐帧互斗，表现为根部抽搐；左右静止半径不同，只有一侧明显。

## 四、弯曲约束与重力

- 弯曲约束每帧施加一次，系数 = 根到梢递减曲线 × 增益。写进距离迭代里会被迭代次数放大成刚体。
- 曲线由根到梢递减（1.0 到 0.1；本工程实机取 0.18 到 0.05）。梢端系数过小时重力把整链拉直，轮廓塌成一条直线。
- 静止下沉约等于「重力分量 / 系数」沿链累积。16 节链条在梢端系数 0.05 时下沉约 65 厘米，必须把梢端抬到 0.25 以上，或把重力改成垂直于段方向的分量。
- 重力取垂直于段方向的分量：链条张力抵消沿链重力，静止时为零，运动时有重量。

## 五、标定

- 指标：发梢相对刚体跟随位置的位移峰值。
- 反馈：`gain *= (实测 / 目标) ** 0.7`，5 轮，容差 0.1；增益越高越硬、位移越小。
- 标定口径要落在关节平均偏转角或相邻节夹角上。只压发梢位移会把每一节都收紧，形状依旧硬。

## 六、循环接缝与穿插

- 循环片段首末帧必须一致：待机在标定后多跑两遍 SEAM_PASSES，实测 0.194 度；校验方式是首末帧骨骼世界位置差与未受力的脚骨同量级。
- 身体轮廓：每 5 厘米高度带取 98 分位半径，剔除 `Bone_Hair*` 与 `Bone_Piao*` 主导的顶点，碰撞余量 0.3 厘米。

## 七、判定

- 入包后用 `NexusAnimAmp.exe` 读轨道：发骨局部幅度 12 到 26 度、裙骨 1 到 2 度属正常。
- 朝向节点密度：本工程曲线拟合后约 3.4 个/秒/轨；参考 SkyCastle 是 59.5 个/秒/轨（60 帧采样）。节点越稀，快动作越容易被抹平。

## 八、增加骨节

目的：把弯折分摊到更多关节，避免 15 厘米节距上出现折点。

1. 原骨的头尾与矩阵保持不动；新骨插在节中点，`align_roll` 复制父骨滚转，再把子骨改挂到新骨。
2. 通道基准 `anim_channel_map.tsv` 按当前静止姿态重算（`cn6_local(rest, parent_rest)`）。改挂父骨后子骨的静止局部平移从整节变成半节，沿用旧基准会让链条每节拉开半个节长。
3. 入包前用 `NexusBoneCurve.exe <模型.fgx> <动画.fgx>` 转储：静止时新骨应是零平移与单位四元数。出现固定角度（例如 47 度）说明滚转或基准错了。

失败特征：整条发辫偏向一侧、看起来接近垂直。成因是原骨矩阵被改动后，增量通道多转一个固定角，子骨全部继承。

## 九、参考数据（体积与采样）

| 参考 | 轨道数 | 采样 | 体积 |
|------|--------|------|------|
| Denia_Pack | 2,492 到 3,575（模型 4,110 根骨） | 中位 1.56 个节点/轨 | 461 KB 到 4.7 MB |
| SkyCastle（3811836710） | 181 | 319 个节点 / 5.3 秒 | 2.0 MB |
| 今汐工程 | 218 | 107 个节点 / 36.7 秒 | 0.05 到 0.2 MB |

参考文件的体积差异来自骨骼数量与采样密度，与片段时长无关。

## 十、素材自带的次级运动层

素材侧另有成套的次级运动片段（命名形如 `Rib_<动作>`）时，直接覆盖旋转通道比程序化解算更省事，效果也更接近游戏内。

- 语义：这类轨道存的是相对 RefPose 的绝对局部姿态；基座发丝、裙摆、披帛的静止姿态恒为 RefPose，因此可以整条覆盖旋转四元数，按 1:1 写入，不做增益、不做偏移。
- 覆盖与弹簧互斥。同一个族要么由次级运动片段驱动，要么由角度弹簧驱动；两层同时写同一条通道会互相抵消。
- 片段选择按次级运动目录里 `.ueanim` 是否真的存在来判定，不要在导入前用动作表判断——导入发生在之后，那时动作表必然是空的。
- 帧长换算：输出帧号映射到源片段帧号时按 `offset = round(local * (rib_len - 1) / (base_len - 1))` 铺满，否则会压缩到片段前段。
- 判据：`NexusAnimAmp.exe` 读轨道，节点数大于 1 才算真有曲线；发骨局部峰值 21 到 83 度、裙骨 4 到 23 度、披帛 20 到 126 度是已验收工程的实测区间。

鸣潮素材的三处次级运动目录、条数与轨道语义见 `references/wuwa-notes.md` 第四节 <!-- WUWA -->

## 十一、没有专用片段时的取舍

素材里没有 `Rib_*`、只剩身体片段可借时，借用会带来两个必然缺陷：

- 借用片段帧长远短于输出片段，逐帧取整把运动变成阶梯，待机表现为低幅度高频抖动。
- 借用片段的发丝摆幅是那一段动作的量级（实测 165 到 178 度），换到别的身体动画上就是乱飘。

这类角色回到角度弹簧层，由它自己的骨骼运动驱动，抖动与乱飘同时消失。幅度按族标定，御三家工程取发梢位移 4 到 5.7 厘米，实测待机接缝 0.0 度、发骨局部峰值 16 度。

## 十二、重采样：输出帧数不得大于源帧区间跨度

采样公式为 `src = start + int(round(span * i / out_frames))`。`out_frames` 大于 `span` 时，输出帧数多于源区间可用帧数，必然有若干输出帧读到同一个源帧，时间轴上表现为「停一帧、走一帧」交替。这个阶梯在离躯干最远的部位被放大得最明显，实测表现为右手在待机时轻微抖动。

女漂 `Stand2` 源帧 0..80 共 81 个采样点，写成 121 帧输出时产生 41 个重复帧：

```
IDLE_A  src=0..80  out=121  dupes=41  step_set=[0, 1]
IDLE_A  src=0..80  out=80   dupes=0   step_set=[1]
```

判据是 `dupes == 0` 且相邻步长集合为 `[1]`，用 `scripts/unit/resample_audit.py` 跑：

```
python scripts/unit/resample_audit.py --clip IDLE_A:0:80:80 --clip IDLE_COMBAT_A:0:75:75
```

输出帧数取源区间跨度（不是跨度加一）时步长恒为 1。帧数变少会改变片段时长，取舍前先确认时长目标。
