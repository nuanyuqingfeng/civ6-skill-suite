# 失败归因纪律（怀疑工具，而不是先怀疑素材）

> 一句话：**连续两次修不好，先别动素材——去证明工具在骗你。**

`acceptance.md` §假信号应对通则 已经写了"单一通道先怀疑仪器"，但那段话藏在参考文件末尾，实务中形同注脚。本文把它变成可执行的触发器。

## 一、为什么工具比素材更该被怀疑

| 偏见 | 表现 | 现实 |
|---|---|---|
| 成本不对称 | 改素材是明确动作，证明工具错要先造实验 | 造实验通常只要 10 分钟 |
| 成功路径惯性 | "这套链跑通过，它是对的" | 跑通过 ≠ 在**当前输入**上是对的 |
| 归属偏见 | 素材是外来物，天然可疑；工具是自己写的，天然可信 | 自己写的脚本**没有第三方验证** |
| 不报错即可信 | 工具正常返回，就默认数据正确 | 最危险的是**静默地返回错误数据** |
| 同源验收 | 用自己的脚本验收自己的产物 | 脚本的盲区就是结论的盲区，且不会自曝 |

## 二、案例矩阵（误判 → 真因 → 判别法）

| 现象 | 当时归因 | 真因 | 判别法 |
|---|---|---|---|
| 动画逐骨差分全绿，实机完全没表情 | 曲线权重、形态键、blink 通道 | 几何 mesh palette 里**一根面骨都没有** | 查 `FAM(面骨)` 主导顶点数，见 `face-skin-gate.md` |
| 读数工具连续崩溃 | "Granny 工具偶发""资产损坏" | **输出路径过长触发 native 缓冲区越界** | 换短路径重跑；能稳定复现就不是"偶发" |
| cook 成功但 BLP 字节完全不变 | "几何没进包" | 拿两轮**都没有变化**的产物互比，基准就错了 | 必须与**变更前备份**比，不能与"上一轮没变的结果"比 |
| 某段保护逻辑"从未触发" | blink=0 / 被限幅抵消 | 条件本来就已满足，**我压根没打印中间量** | 先打 A、B 实际值，再谈"被抵消" |
| 下眼睑位移只有应有值的 1/7 | 形态键把位移抵消了 | 导出链路换轴 + 压缩 | 看最终 fgx 的局部轴与幅度，不看 Blender 世界坐标 |
| 贴图工具报 `textured=0` | "素材是 PNG，不支持" | 工具只扫工程 `Textures` 下的 `.dds` | 把工具的限制当成素材的属性 |
| 同一角色"同资产不同形状" | "游戏资产本来就这样" | 解包工具未绑补丁包密钥，读到**旧 revision** | 不同工具读同一资产结果不同 → 先查版本，再查处理 |
| 用户说「上一版是对的」，按语义重建还是错 | "我记得那一版改了什么" | 用户锚的是**文件**（时间/截图），不是描述 | 按 jsonl 时间戳 + mtime + sha 反查，列清单让用户勾（§五·5） |

最后两条是同一类：**工具安静地返回了错误数据**。没有异常、没有警告、格式合法。

## 三、四个自检问句（任何结论前）

1. 这个数是从**哪个文件**读的？它是产物、中间态，还是缓存？
2. 有没有**第二条独立通道**能读到同一事实？
3. 如果工具是对的，这里应该是什么**量级**？实测差了几倍？
4. 我做过一次**会失败**的实验吗？（如果所有实验都通过，说明实验没有区分力）

## 四、硬触发器

满足任一条，**停止修改素材/资产**，转入工具取证：

| 触发器 | 动作 |
|---|---|
| 同一现象第 2 次修复仍复现 | 冻结改动，列出"这条链上每个工具/脚本"，逐个做对照实验 |
| 实测值与应有值偏差 > 2 倍 | 先证明读数可信，再谈原因 |
| 连续多次"验收全绿"但实机不对 | 验收脚本作废，先做反向闸门（第五节） |
| 工具报错但换输入就好 | 不是素材问题，是输入形态问题（路径长度/编码/大小写/权限） |
| 两个工具读同一资产结果不同 | 先查版本与数据源完整性 |
| 交付后被指「不是这一版」「你把上一版的毛病又带回来了」 | 停手做时间锚定（§五·5），**不做第二次语义猜测**；第二次猜错就等于浪费两轮 |

## 五、四个取证动作

**1. 反向样本法**（证明"工具确实读了这份输入"）
故意喂一个差异极大的输入，看产物是否剧烈变化。不变 → 工具没读它。
实例：把 A 角色的几何塞给 B 角色的 cook，BLP 从 24.7 MB 掉到 18.7 MB，一步证明 cook 确实在读几何文件；而改 `.geo` 注释后产物不变，则反过来证明缓存按内容判定。

**2. 健康样本法**（证明"工具在这台机器上能工作"）
拿一个已知正确的资产跑同一工具。健康样本也失败 → 环境/工具问题，与素材无关。

**3. 最小复现**（把长路径/大数据/多角色逐项剥掉）
今天多数"偶发"崩溃都能被最小复现降级为确定性缺陷。

**4. 反向闸门**（让验收脚本自曝盲区）
对任意闸门脚本注入一个已知错误（清零某根骨权重、改坏一个字段），它**必须 FAIL**。注入后仍 PASS → 该脚本作废，不是"资产没问题"。
工具：`scripts/gate_selftest.py`。

**5. 时间锚定法**（证明"用户要的是哪一个文件"）
用户用时间或截图指认历史产物时（「就要 15:37 那一版」「就是这一张」），他锚的是**文件**，不是语义描述。按"我记得那一版改了什么"重建，必然滑到相邻版本。

```bash
# 1) 会话记录按时间戳捞当时的产物路径（留 3~5 分钟余量）
grep -n "\.blend\|\.dds\|\.png" "$USERPROFILE/.workbuddy/projects/<工程>/<会话 id>.jsonl" | head -50
# 2) 用文件 mtime 对齐，sha 前 16 位做指纹
ls -l --time-style=+%H:%M <产物目录>/*.blend
```

三步交付：先出「时间 → 文件 → 字节数 → sha16」清单，让用户点名勾选；勾定后再动手；动手前把该文件另存为 `_ANCHOR` 副本，后续所有轮次都与它比对。
实例：长离刘海连续交付三次错误版本（第 2、3 次是同一份被否决的口径），用户明确训斥「完整从会话开始读起」后才改按 jsonl 时间戳定位，一次命中。

## 六、证据等级

| 级 | 定义 | 能否作为交付依据 |
|---|---|---|
| A | 两条独立通道实测一致 | 可以 |
| B | 单通道实测 | 可以，但需注明通道 |
| C | 推理/类比/经验 | **不可以** |

常见错误是把 C 级当 A 级用："应该是被形态键抵消了"——这是 C；"实测 A=0.6、B=−0.09"——这才是 B。

## 七、黑箱标定卡

给每个外部工具记一行，只记一件事：**它曾经怎样安静地返回错误数据**。

| 工具 | 已知的静默失败方式 |
|---|---|
| 解包器（FModel 等） | 未挂全部补丁包/密钥 → 返回旧 revision 资产，无警告 |
| Cooker | 按内容 hash 判依赖；源文件没变则复用缓存，产物字节不变 |
| Granny 读数 exe | 输出路径过长 → native 越界崩溃（不是"偶发"） |
| 回读工具 | 输入与输出同目录 → 文件占用异常 |

这张表比"工具怎么用"值钱：用法写在文档里，静默失败只存在于事故里。
