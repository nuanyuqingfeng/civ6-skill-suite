# 静止姿态锚点（单位类资产的动画闸门）

适用：`m_ClassName=Unit` 的单位资产，以及任何「动画一挂上模型就巨大、悬空、肢体散架」的现场。
本文是 `acceptance.md` §Q/p_Q 的前置闸门：先用本文证明片段与模型的静止姿态同源，再谈反解烘焙。

## 一、闸门判据

一条硬判据、两条诊断。全部对**最终 fgx** 实测，Blender 里的估算不作数。工具在 `<转换宿主>`（本机 `E:\SoftWares\civ6_nexus_work\CivNexus6`）。

```bash
NE="E:/SoftWares/civ6_nexus_work/CivNexus6"
"$NE/NexusRestDump.exe"  "<工程>/Geometries/<资产>.fgx"                         # 静止姿态：$4-$6 是 p，$7-$10 是 q0..q3
"$NE/NexusCurveDump.exe" "<工程>/Animations/<片段>.fgx"                         # 片段：Root 块内第 3 行是 ori(0)，Bip001 同法取 pos(0)
"$NE/NexusPoseDump.exe"  "<工程>/Geometries/<资产>.fgx" - <out_rest>.tsv        # 静止姿态合成
"$NE/NexusPoseDump.exe"  "<工程>/Geometries/<资产>.fgx" "<片段>" <out_clip>.tsv  # 片段首帧合成
```

### A（硬判据，唯一能区分可用与不可用）

除 `TURN_*` 外，每条片段 `Root` 的 `ori(0)` 与静止姿态 `Root` 四元数绝对点积 ≥ 0.99999（≤0.3°）。

| 片段集 | A 实测 | 实机 |
|--------|--------|------|
| 定稿 27 条 | 27/27 点积 1.000000000 | 正常 |
| 女漂原片段 22 条 | 22/22 点积 1.000000000（`TURN_L` 点积 0.0，按设计整体旋转根骨，豁免） | 正常 |
| 90° 偏移坏集 27 条 | 点积 0.500000（120.0000°），25 条判失败 | 巨大、悬空、错乱 |

失败特征：`Root` `ori(0)` 出现 `(0,0,0.707,0.707)`（绕 Z 90°）即源骨架朝向未消，见 §三第一个常数。

### B（诊断，不判失败）

`Bip001` 的 `pos(0)` 允许等于静止姿态，也允许全零，两种都有可显示的实例：

| 片段集 | `Bip001` `pos(0)` | 与静止姿态各轴差 | 实机 |
|--------|--------------------|------------------|------|
| 定稿 | `(1.016,85.351,0.000)` | 0.0004 厘米 | 正常 |
| 女漂原片段 | `(0.000,0.000,0.000)` | 86.25 厘米 | 正常 |
| 90° 坏集 | `(0.000,1.016,85.351)` | 轴向置换 | 错乱 |

位移通道不参与判真，但它会暴露坐标系被整体旋转：三个轴循环移位即源骨架框架未消。看到置换先查 A。

### C（诊断，不判失败）

首帧逐骨合成位置与静止姿态的欧氏距离。

| 片段集 | C 实测 | 实机 |
|--------|--------|------|
| 定稿 | 0.0063 厘米（`Bip001LThighTwist1`） | 正常 |
| 女漂原片段 | 84.63 厘米（`Bip001`） | 正常 |
| 90° 坏集 | 119.99 厘米（`Bip001`） | 错乱 |

同一个指标在可用资产上横跨 0.0063 到 84.63 厘米，所以它的绝对值不携带判真信息。报「首帧偏差 0.0000 厘米因此合格」是无效结论；坏集的 C 甚至比某些可用集更接近 0。

## 二、单位类资产的两个常数

- **源骨架相对游戏骨架的朝向差**：psk/ueanim 家族骨架与 cn6 游戏骨架的静止姿态差为 `Rz(90.000009°)`，60 骨残差 ≤0.0003 厘米。该差必须乘进目标骨的世界旋转，否则片段从第 0 帧就横倒。
- **根节点 100 倍单位换算**：cn6 导入器在骨架根节点写 `diag(100,100,100)`，骨架对象要设 `arm_c.scale=(0.01,0.01,0.01)`。与领袖链同值，见 `acceptance.md` §Q/p_Q 末条。

## 三、先做一条，过闸再批量

只做 `IDLE_A`，A 达标才允许做其余片段。不达标的产物不许进工程。失败读数一并留档，例：第一版把世界平移直接写成静止世界头位置，C = 12.5396 厘米、31 根骨超阈；改成由静止局部平移做正向动力学累乘后 C = 0.0063 厘米。

## 四、反解落法

`in_q = Q_b⁻¹ ⊗ T_q ⊗ EPS`、`in_p = Q_b⁻¹·(T_p − p_Q_b)`，EPS=0.01° 固定微旋；`Q_b`、`p_Q_b` 逐骨标定，方法与探针 FBX 见 `acceptance.md` §Q/p_Q 与 `SKILL.md` 第 7 步。单位类资产与领袖链共用同一张表格式，换骨架必须重标。

## 五、执行脚本

```bash
python scripts/check_clip_anchors.py "<工程目录>"                        # 默认取 Geometries 下最大的带 .geo 的 fgx
python scripts/check_clip_anchors.py "<工程>" --geo <模型.fgx> --anim-dir <片段目录>
```

逐条输出 A/B/C 实测值与判定，A 不达标即非零退出；`TURN_*` 标 `SKIP_TURN`，B/C 超阈但 A 达标标 `PASS_DIAG`。批量烘焙后、cook 之前跑一次。

## 六、走过的错路

细节记在 `gotchas.md` §单位（Unit）资产实战：把帧 0 增量当局部旋转、Blender 重定向保留源骨架朝向、只信 PoseDump 绝对值、手工按列号读 PoseDump。
