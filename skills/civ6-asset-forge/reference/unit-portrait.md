# 单位肖像（圆形 / 放开两分支）· 规格与构图

> 来源：用户 2026-10-27 提供的 `单位肖像模板.psd`（256×256，圆形画面 + 人物示范），实测反推圆心与半径，并导出为内置蒙版。

## 〇、先判型（两类，处理方式不同）

| 形态 | 判据（看图，或直接问用户） | 处理 |
|---|---|---|
| **半身像 / 头像**（头肩、胸像、脸部特写） | 画面里只有头部与肩胸，看不到腰线以下 | **圆形分支**：套内置圆形模板，下边缘不溢出，上边缘允许少量溢出 |
| **完整人物立绘 / 单位肖像（全身）** | 有腰线以下、腿脚或完整站姿 | **放开分支**：不套圆，只压小画幅占比，右侧留出参数栏 |
| **不规则生物**（动物、浮空生物、非人形轮廓） | 轮廓不是人形，按外接框算占比 | **放开分支**：同上 |

判型靠看图。**读不了图或两种形态都可能时，直接问用户属于哪一类**——本 skill 明确允许为此提问，不自行猜。
判错的代价：圆形分支套在全身像上会切掉腿脚，放开分支套在半身像上会让脸在圆形控件里被切边。

## 一、这是什么 / 什么时候用

单位面板里的肖像图标：`ICON_UNIT_<X>_PORTRAIT` 一类，走 `IconTextureAtlases` 图集（`Filename` 指向 `.dds`），
**不走** `.tex`/XLP/BLP 链，注册方式见 `civ6-modding` 的 `art-pipeline.md`。

**本类不做**：单位 3D 模型、单位晋升徽章（→ `reference/promotion-icon-sizes.md`）、领袖头像（→ `reference/leader-avatar.md`）。

## 二、圆形分支：圆形规格（模板实测，256 画布）

| 项 | 值 |
|---|---|
| 画布 | 256×256 |
| 圆心 | **(121.5, 115.5)**（归一化 0.4746, 0.4512） |
| 半径 | **110**（直径 220，占画布宽 85.9%） |
| 圆外留白 | 左 11.5 / 右 24.5 / 上 5.5 / 下 30.5 |
| 内置蒙版 | `templates/unit_portrait/unit_portrait_circle_256.png`、`unit_portrait_circle_1024.png`（L 通道，白=保留） |

1024 母版：圆心 **(486, 462)**、半径 **440**，与 256 版同一几何按 4 倍放大。

圆心不居画布中心，纵向明显偏上：底部留白 30.5px，是给圆形控件的边框与投影让位。

## 三、圆形分支：越界规则（硬性）

1. **下半部分严格不超出**：素材 alpha 的最下沿必须落在圆底（y ≤ 225.5）之上，且与圆底至少留 1px。
   素材自身以圆形作为边界时（alpha 即圆），**alpha 一律不得越过该圆**。
2. **上半部分允许少量超出**：头顶发饰、长发、帽檐可以越过圆顶，最大不超过画布上沿（y ≥ 0）。
3. **左右**：按圆收边，不得越过圆的左右极值（x ≥ 11.5、x ≤ 231.5）。
4. 判定口径：圆外 alpha>8 像素数为 0；若因抗锯齿残留，允许半径外 0.6px 以内的零星像素。

圆形分支与领袖头像同源规则：**出圈只留上半区的发饰/角/耳等不规则延伸，向下与左右下方一律不留**（见 `reference/leader-avatar.md` 「圆缘贴合与出圈三规则」）。

## 四、圆形分支：构图配方（四步）

1. **取胸前半身**：源图 alpha>8 求内容框；令 `y0` = 内容框顶行，
   头部横心 `cx` = 源图顶部 12%（图高）这一段内 alpha 加权质心的 x。
2. **方形裁切**：边长 = 图高 × **0.55**，左上角 `(cx − 边长/2, y0)`；超出源图边界时按源图裁切。
3. **落位**：方形等比缩放到 **2r**（256 画布为 220，1024 为 880），贴到圆的包围盒左上角
   （256 画布即 (11.5, 5.5) 取整，1024 即 (46, 22)）。
4. **蒙版**：alpha 乘以内置圆形蒙版（按 4~8 倍超采样后缩小，保证边缘平滑）。
   上半部分允许超出的发饰按 §三 第 2 条保留，下半部分仍按圆裁。

## 五、放开分支：完整人物 / 不规则生物

**不套圆**，保留素材自身的 alpha 轮廓；四条边与画布边缘不做硬性留白要求（允许出画布被裁）。

| 项 | 值 | 理由 |
|---|---|---|
| 主体高度 | ≤ 画布高 **0.78** | 占满整幅会把下方单位信息压没 |
| 主体宽度 | ≤ 画布宽 **0.62** | 横向太宽会压到右侧参数栏 |
| 水平位置 | 左缘留 **4%~8%** 画布宽，主体整体偏左 | 右侧预留 **≥30% 画布宽**的参数栏区 |
| 垂直位置 | 底边贴齐画布下缘 | 与面板底边对齐，不悬浮 |

配方：取源图 alpha>8 内容框 → 等比缩放到上述占比（先看高度、再看宽度，取更严的一侧）→
按「左缘 4%~8%、底边贴齐」粘贴 → 不乘任何圆形蒙版。

占比拿不准、或素材本身已经是带边框的成品图标时，问用户要哪个占比（本 skill 允许此提问）。

## 六、图集与接线

| 项 | 值 |
|---|---|
| 图集 | `ATLAS_YSJ_ICON_UNITPORTRAITS`（本项目 3×1：忧昙 0 / 踏白 1 / 今巡尉 2） |
| 档位 | 38 / 50 / 70 / 95 / 200 / 256 |
| 注册 | `Data/Icons_YSJ.xml` 的 `IconTextureAtlases` 每条一档 + `IconDefinitions` 的 `Index` |
| 换图 | 先出 256 母版图集，再 `python <civ6-modding>/art/regen_atlas_tiers.py <工程根> --atlas ATLAS_YSJ_ICON_UNITPORTRAITS --master 256 --sizes 38,50,70,95,200 --write` |

## 七、校验

1. **圆形分支**：每格 `alpha > 8` 的像素全部落在圆内（半径 + 0.6px 容差）；alpha 最下沿 ≤ 225.5（256 档）或 ≤ 902（1024 母版）。
2. **放开分支**：每格 alpha 内容框高度 ≤ 0.78×档位、宽度 ≤ 0.62×档位、右缘距画布右缘 ≥ 0.30×档位。
3. 图集宽度 = 档位 × 格数，`.dds` 头为 RGBA 掩码、无 mips。
4. 六档与 `IconTextureAtlases` 的 `IconSize`/`IconsPerRow` 一致。
